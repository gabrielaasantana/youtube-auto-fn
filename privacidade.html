Política de Privacidade — Upload YouTube FN

Última atualização: 26 de novembro de 2026.

O Upload YouTube FN é uma ferramenta pessoal e interna, usada por uma única pessoa para automatizar o envio de gravações de reuniões para o YouTube. Esta política explica, de forma simples, quais dados o aplicativo acessa e como são tratados.

Que dados o aplicativo acessa

  • Google Agenda (somente leitura): para identificar as reuniões e localizar o anexo da gravação.
  • Google Drive (somente leitura): para baixar o arquivo de vídeo da gravação da reunião.
  • YouTube (envio): para publicar essa gravação no canal do próprio usuário, como "não listada".

Os escopos de acesso usados são: calendar.readonly, drive.readonly e youtube.upload. O aplicativo nunca escreve, altera ou apaga dados na Agenda nem no Drive.

Como os dados são usados e armazenados

  • O processamento acontece localmente, no computador do próprio usuário. Não há servidores próprios nem banco de dados online.
  • As credenciais de acesso (tokens) ficam guardadas apenas no computador do usuário.
  • O arquivo de vídeo é baixado temporariamente só para o envio e apagado em seguida. O vídeo final fica no canal do YouTube do próprio usuário.

Compartilhamento

Os dados não são vendidos, compartilhados nem transferidos a terceiros. O acesso é usado exclusivamente para a finalidade acima.

Uso conforme as políticas do Google

O uso das informações das APIs do Google por este aplicativo segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Contato

Dúvidas sobre esta política podem ser enviadas pelo e-mail de suporte configurado na tela de permissão do próprio aplicativo.
